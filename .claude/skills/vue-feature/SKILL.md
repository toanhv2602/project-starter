# Vue Feature Engineering

- Inspect routes, layouts, shared components and composables first.
- Use Composition API and `<script setup lang="ts">`.
- Use TanStack Query for remote/server state and Pinia for client-owned shared state.
- Keep components focused; extract composables for reusable behavior.
- Implement loading, error, empty and success states.
- Do not rely on frontend guards for authorization.
- Add component/composable tests and verify accessibility basics.
